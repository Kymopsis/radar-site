Firmware

Le plus simple est le bouton Installer le firmware de la page d'accueil (Chrome ou Edge sur ordinateur, carte en USB). Les mêmes fichiers sont sur GitHub : versions de Radar Base. Le firmware 0.9.2 et les suivants incluent les applis radar (présence 3D ; fréquence respiratoire et cardiaque).

Radar Studio pour Windows

Télécharger Radar Studio 0.9.1 pour Windows (64 bits, environ 60 Mo, sans installation ; SHA-256 dans la version).

« Windows a protégé votre PC »

Radar Studio n'est pas encore signé, donc Windows SmartScreen peut le bloquer la première fois. Choisissez Informations complémentaires, puis Exécuter quand même. Comparez le SHA-256 du fichier avec la page de la version si vous voulez être sûr qu'il s'agit de l'original.

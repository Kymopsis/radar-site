Home Assistant

Radar Base는 MQTT 디스커버리를 통해 Home Assistant에 자동으로 나타납니다. MQTT 브로커는 직접 사용하는 것을 씁니다. 일반적으로는 Home Assistant의 Mosquitto broker 애드온을 씁니다. Kymopsis는 브로커도 클라우드도 운영하지 않으며, 데이터는 내 네트워크 밖으로 나가지 않습니다.

준비물

  • Mosquitto broker 애드온과 MQTT 통합 구성요소가 있는 Home Assistant, 또는 직접 운영하는 다른 MQTT 브로커.

브로커의 주소, 포트(보통 1883), 사용자, 비밀번호를 메모해 두세요.

  • 2.4 GHz Wi-Fi 네트워크, 또는 2.4 GHz와 5 GHz가 같은 이름을 쓰는 듀얼 밴드 네트워크. ESP32-S3에는

5 GHz 무선이 없습니다.

  • Radar Base 펌웨어 0.9.1 이상(브라우저에서 설치).

설정 방법

  1. Wi-Fi에 연결합니다: Radar Base 앱(USB 또는 보드의 핫스팟으로)을 열고 기기 설정, Wi-Fi로 이동합니다.
  2. 기기 설정의 스마트홈에서: 브로커 주소, 포트, 사용자, 비밀번호를 입력한 다음 MQTT를 켭니다.
  3. Home Assistant에서 설정 → 기기 및 서비스 → MQTT를 엽니다. Kymopsis Radar Base가 엔티티와 함께 표시됩니다. 그 밖에 설정할 것은 없습니다.

실행 중인 레이더 앱이 보고하지 않는 값은 비어 있거나 알 수 없음으로 표시됩니다. 호흡수와 심박수는 웰니스 용도로만 사용하세요. 의료용이 아닙니다.

온라인과 오프라인

보드는 가용성 토픽을 게시합니다. 보드에서 MQTT를 끄면 기기는 즉시 사용 불가가 됩니다. 보드의 전원이나 Wi-Fi가 끊기면 브로커가 약 45초 뒤에 사용 불가로 표시하며, 보드가 다시 연결되면 저절로 돌아옵니다.

문제 해결

문제해결 방법
기기가 나타나지 않음보드의 스마트홈 페이지가 연결됨으로 표시되는지 확인하세요. 브로커의 사용자와 비밀번호도 확인합니다.
보드가 Wi-Fi에 연결되지 않음2.4 GHz 네트워크 또는 이름이 같은 듀얼 밴드 네트워크를 사용하세요. 5 GHz 전용 네트워크는 동작하지 않습니다.
kymradar.local이 열리지 않음해당 컴퓨터의 VPN이나 프록시가 .local 이름을 가로챌 수 있습니다. 끄거나 .local을 직접 연결로 두거나, 보드의 IP 주소를 여세요.
거리가 피트로 표시됨Home Assistant는 설정한 단위 체계를 사용합니다. 설정 → 시스템 → 일반 → 단위 체계: 미터법.

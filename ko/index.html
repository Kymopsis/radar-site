Radar Base

Radar Base는 60 GHz 밀리미터파 레이더 모듈을 컴퓨터, 휴대폰, 스마트홈에 연결합니다. 레이더 연산은 레이더 자체 칩이 처리합니다. Radar Base는 레이더 앱을 불러오고, 그 결과를 하나의 간단한 JSON 형식으로 바꿔 USB와 Wi-Fi로 제공합니다.

완성된 레이더 앱 실행3D 사람 위치, 낙상 감지, 호흡수와 심박수. 코딩이 필요 없습니다. USB로 브라우저에서 사용연결하고 Chrome 또는 Edge에서 이 사이트를 열면 끝. Wi-Fi가 필요 없습니다. 집 Wi-Fi에 연결집 안의 어떤 휴대폰이나 컴퓨터에서도 http://kymradar.local로 접속하세요. 나만의 연동 개발어떤 프로그램에서든 USB나 WebSocket으로 결과를 JSON으로 읽으세요.

전체 구성

구성 요소하는 일
레이더 모듈레이더 앱을 실행합니다. 각 앱이 신호 처리 전체를 레이더 안에서 수행하고 결과를 보고합니다
Radar Base (ESP32-S3)레이더 앱을 불러오고, 결과를 JSON으로 변환하고, 원시 데이터를 스트리밍하고, 웹 앱을 제공하고, Wi-Fi에 연결합니다
웹 앱작업을 고르고, 실시간 결과를 보고, 설정을 바꿉니다. Wi-Fi와 USB에서 같은 앱이며 11개 언어를 지원합니다
직접 만든 코드USB나 WebSocket으로 JSON 결과를 읽습니다
스마트홈MQTT로 Home Assistant(자동 검색), ESPHome 컴포넌트

시작하기

이 가이드는 상자를 열고 실시간 레이더 결과를 볼 때까지 약 15분이면 됩니다.

준비물

  • Radar Base 컨트롤러(ESP32-S3 보드)와 캐리어 보드에 장착된 60 GHz 레이더 모듈
  • 점퍼선 10개(암-암) - 키트에 포함
  • USB 케이블 2개: 하나는 Radar Base용, 하나는 레이더 캐리어 보드 전원용
  • Chrome 또는 Edge가 있는 컴퓨터(Windows, macOS, Linux 또는 ChromeOS)

1. 레이더 캐리어 보드 준비

캐리어 보드의 시리얼 헤더(J9)와 P19 / GND / P12 부트 헤더에서 점퍼 캡을 모두 빼세요. 그렇지 않으면 캐리어 보드 자체의 USB 시리얼 칩이 같은 배선에서 Radar Base와 충돌합니다.

2. 배선

먼저 모든 전원을 끕니다. GND를 먼저 연결하고 나머지를 연결하세요. 라벨은 레이더 캐리어 보드에 인쇄된 것을 기준으로 합니다.

Radar Base 핀레이더 캐리어 라벨용도
GNDGND공통 접지(먼저 연결)
GPIO17RX0레이더 앱으로 보내는 명령
GPIO18TX0레이더 앱에서 오는 결과
GPIO15RX1레이더에 앱 불러오기
GPIO16TX1불러오는 동안의 응답
GPIO4RST레이더 리셋
GPIO5P12부트 선택(데이터 선택 겸용)
GPIO6P19부트 선택
GPIO12SPI CLK원시 데이터 클록(원시 데이터 용도에만)
GPIO11SPI MOSI원시 데이터(MISO는 사용하지 않음)

레이더는 자체 캐리어 보드에서 전원을 받습니다(최대 약 600 mA). 컨트롤러 보드의 3V3 핀으로 전원을 공급하지 마세요.

3. 올바른 순서로 전원 켜기

  1. 컨트롤러의 USB라고 표시된 포트를 컴퓨터에 연결합니다. (UART 포트는 컨트롤러 자체 펌웨어를 업데이트할 때만 씁니다.)
  2. 그다음에 레이더 캐리어 보드에 전원을 넣습니다.

Radar Base는 시작하자마자 레이더의 부트 핀을 설정하므로, 레이더는 나중에 켜져야 합니다. 순서를 반대로 했다면 진단을 열고 레이더 다시 시작을 누르세요.

4. 작동 확인

  1. Chrome 또는 Edge에서 앱을 열고 USB 연결을 누른 뒤 "USB JTAG/serial"이라는 이름의 포트를 선택합니다.
  2. 시나리오 실행 → 3D 재실 감지 및 추적을 선택합니다.
  3. 레이더 앞을 걸어 보세요. 내 위치가 파란 점으로 나타납니다.

Datos sin procesar y tus propios algoritmos

Radar Base puede transmitir por USB los datos sin procesar del radar (cada chirp, ambos canales de recepción). El firmware abierto incluye este flujo y sus ajustes; la herramienta de PC para ver y procesar los datos sin procesar no forma parte del repositorio público.

Qué ofrece el firmware abierto

FunciónDónde
Ajustes de datos sin procesar: chirp, ganancia, filtros, antenasApp → Datos sin procesar y ajustes del radar, o consola cfg <key> <value>
Autoprueba del enlace de datos: se revisa cada bloqueApp → Datos sin procesar y ajustes del radar → Iniciar prueba
Resultados en JSON para tu propio códigoResultados JSON y API

Dónde ejecutar un algoritmo

Haz el prototipo en el PC. Luego comprueba si el hardware FFT y CFAR del propio radar puede hacer el trabajo; si es así, debe ejecutarse en el radar y solo salen los resultados. Si no, prueba con el ESP32, y déjalo solo en el PC si ninguno de los dos sirve.

Comprueba el enlace de datos

App → Datos sin procesar y ajustes del radar → Iniciar prueba. Ejecuta la app de datos sin procesar unos segundos y revisa cada bloque: los bloques dañados y los ausentes deben ser 0.

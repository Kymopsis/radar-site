Resultados JSON y API

Todos los clientes - la app, Home Assistant, tu propio código - leen los mismos resultados: un objeto JSON por línea, versión de esquema 0.

Dónde leerlos

ConexiónCómo
USBEnvía jsonout on por la consola serie; las líneas JSON llegan entre las líneas de registro
Wi-FiWebSocket ws://kymradar.local/ws (una o más líneas por mensaje)

Mensajes

tCamposNotas
capapp (hd3d, fall, vital), mounts, mountSe envía al iniciar un escenario, al cambiar el montaje y cada 5 s
targetsts (ms), targets: [{id, x, y, z}]Metros. x a la derecha, y alejándose del radar (plano del suelo si está en el techo), z hacia arriba
zoneszones: [{id, occupied}]Zonas 1-4; se envía al cambiar y cada segundo
fallstate (none, normal, fall), countSe envía al cambiar y cada segundo
vitalts, br, hr (por minuto), dist (m)Las frecuencias se omiten mientras no se mide a nadie

Cada mensaje lleva "v": 0. Ignora los mensajes con otra versión.

{"v":0,"t":"cap","app":"hd3d","mounts":["ceiling","side"],"mount":"side","fov_deg":55}
{"v":0,"t":"targets","ts":42097,"targets":[{"id":1,"x":0.268,"y":1.42,"z":0.05}]}

Comandos (consola USB o app)

ComandoQué hace
verPregunta la versión a la app del radar
ram <file>Ejecuta una app del radar desde la memoria del radar
resetReinicia el radar desde su flash
jsonout on/offResultados JSON por USB
tf 0201 13000000 / 14000000Presencia 3D: montaje en techo / pared
cfg [key value]Ajustes de datos sin procesar
wifi [ssid password], wifi forget, wifi scanWi-Fi doméstico
api files/cfg/wifi/scan/mqtt/batchInformación del dispositivo en una línea JSON (la usa la app por USB)
mqtt <host> [port] [user] [pass], mqtt offHome Assistant a través de tu propio broker MQTT
board [profile]Mostrar o fijar el perfil de placa
u0raw on/offReenviar el puerto de la app del radar byte a byte (captura en bruto)
batch start <firmware>, batch stopGrabación por lotes (firmware del kit de desarrollo)

API HTTP (Wi-Fi)

GET /api/files, GET/POST /api/cfg, GET/POST /api/wifi, GET /api/wifi/scan, POST /api/run?op=..., POST /api/tf?type=&data=, GET /api/log?since=. Las credenciales solo se envían en el cuerpo de un POST.

Cliente de ejemplo en Python: python app_views.py --serial COM5 en la carpeta pc-gui.

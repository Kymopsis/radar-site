JSON の結果と API

すべてのクライアント - アプリ、Home Assistant、あなた自身のコード - が同じ結果を読みます。1 行に 1 つの JSON オブジェクト、 スキーマバージョン 0 です。

読み取り方

接続方法
USBシリアルコンソールで jsonout on を送る。JSON の行がログの行の間に流れてくる
Wi-FiWebSocket ws://kymradar.local/ws（1 メッセージに 1 行以上）

メッセージ

tフィールド備考
capapp (hd3d, fall, vital), mounts, mountシナリオ開始時、設置方法の変更時、そして 5 秒ごとに送信
targetsts (ms), targets: [{id, x, y, z}]単位はメートル。x は右、y はレーダーから遠ざかる方向（天井設置では床面）、z は上
zoneszones: [{id, occupied}]エリア 1-4。変化時と 1 秒ごとに送信
fallstate (none, normal, fall), count変化時と 1 秒ごとに送信
vitalts, br, hr（毎分）, dist (m)誰も測定していない間は数値を省略

すべてのメッセージに "v": 0 が付きます。別のバージョンのメッセージは無視してください。

{"v":0,"t":"cap","app":"hd3d","mounts":["ceiling","side"],"mount":"side","fov_deg":55}
{"v":0,"t":"targets","ts":42097,"targets":[{"id":1,"x":0.268,"y":1.42,"z":0.05}]}

コマンド（USB コンソールまたはアプリ）

コマンド内容
verレーダーアプリのバージョンを問い合わせる
ram <file>レーダーのメモリからレーダーアプリを実行する
resetフラッシュからレーダーを再起動する
jsonout on/offUSB で JSON の結果を出力する
tf 0201 13000000 / 140000003D 在室：天井 / 壁設置
cfg [key value]生データの設定
wifi [ssid password], wifi forget, wifi scan自宅の Wi-Fi
api files/cfg/wifi/scan/mqtt/batchデバイス情報を 1 行の JSON で返す（アプリが USB 経由で使用）
mqtt <host> [port] [user] [pass], mqtt offご自身の MQTT ブローカー経由の Home Assistant
board [profile]ボードプロファイルの表示または設定
u0raw on/offレーダーアプリのポートをバイト単位でそのまま転送（生データ取得）
batch start <firmware>, batch stop一括書き込み（開発キット用ファームウェア）

HTTP API（Wi-Fi）

GET /api/files, GET/POST /api/cfg, GET/POST /api/wifi, GET /api/wifi/scan, POST /api/run?op=..., POST /api/tf?type=&data=, GET /api/log?since=。認証情報は POST の本文でのみ送られます。

Radar Base

Radar Base は、60 GHz ミリ波レーダーモジュールを、あなたのパソコン、スマホ、スマートホームにつなぎます。 レーダーの処理はレーダー自身のチップが行います。Radar Base はレーダーアプリを読み込み、結果をシンプルな JSON 形式に変換して、 USB と Wi-Fi で提供します。

ビルド済みのレーダーアプリを動かす人物位置の 3D 表示、転倒検知、呼吸と心拍。コーディング不要。 USB でブラウザーから使うつないで、Chrome か Edge でこのサイトを開くだけ。Wi-Fi は不要です。 自宅の Wi-Fi につなぐ自宅のどのスマホやパソコンからでも http://kymradar.local で使えます。 独自の連携を作るUSB または WebSocket 経由で、どのプログラムからでも結果を JSON で読み取れます。

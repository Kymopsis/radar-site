ダウンロード

ファームウェア

いちばん簡単なのは、ホームの ファームウェアをインストール ボタンです（デスクトップ版の Chrome または Edge、ボードは USB 接続）。同じファイルは GitHub にもあります：Radar Base のリリース。 ファームウェア 0.9.2 以降にはレーダーアプリ（3D 在室、呼吸と心拍）が含まれます。

Windows 版 Radar Studio

Windows 版 Radar Studio 0.9.1 をダウンロード （64 ビット、約 60 MB、インストール不要。SHA-256 は リリースに掲載）。

対応機能
すべての Radar BaseUSB で接続、シナリオ表示、よく使う設定、スマートホーム（MQTT）設定
Kymopsis Radar Base 開発キットさらに生データ、レンジ-ドップラー、波形とフィルターの設定、独自のアルゴリズム、バイタルサイン / HRV

「Windows によって PC が保護されました」

Radar Studio はまだコード署名されていないため、初回は Windows SmartScreen に止められることがあります。詳細情報を選び、実行を選んでください。元のファイルかどうか確かめたいときは、ファイルの SHA-256 をリリースページと照合してください。

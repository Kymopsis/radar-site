開発キット用レーダー書き込みモジュール

Radar Base のファームウェアには、同じソースからビルドした 2 つのエディションがあります。

エディションできること
オープン版このサイトで紹介するすべて：レーダーのメモリからすべてのレーダーアプリを実行、JSON、Web アプリ、Wi-Fi、スマートホーム
開発キット版オープン版 + レーダー自身のフラッシュに書き込む追加モジュール

モジュールの役割

アプリをレーダーのフラッシュに書き込むと、Radar Base が先に読み込まなくても、電源を入れるだけでレーダーが自分で起動します。 モジュールは書き込みのたびに、レーダーの現在のフラッシュをバックアップします。バックアップに失敗したら何も書き込みません。 バックアップはアプリからいつでも元に戻せます。

開発キット用ファームウェアの提供方法

開発キット用ファームウェアは、開発キットのボードに書き込み済みで届きます。更新は購入者にメールでお知らせします。開発キット用ファームウェアは一般には公開ダウンロードされていません。オープン版ファームウェアは、いつでも公開リポジトリから入手できます。

一括書き込み

多数のモジュールを続けて処理する場合：ファームウェアを一度選び、モジュールを 1 つずつ接続します。各モジュールは検出され、必要に応じてバックアップ、書き込み、検証が行われ、フラッシュから起動してバージョンを取得します。ページとボードのライトに PASS または FAIL が表示され、カウンターが加算され、モジュールごとに 1 行がダウンロード可能な CSV ログに記録されます。

しないこと

  • インターネットには接続しません。
  • データの収集、保存、送信は一切行いません。
  • ファームウェアの他の部分はこのモジュールに依存しません。

非公開なのは、書き込みのためにレーダーへ読み込む小さなヘルパープログラムが、私たちが公開できるものではないためです。 開発キットのユニットでは、このヘルパーはユニットごとに固有の鍵で暗号化して保存されます。

モジュールがない場合

オープン版ファームウェアでも、すべてのレーダーアプリをレーダーのメモリから実行できます（シナリオを実行）。 失うのは「Radar Base がなくても自分で起動する」という便利さだけです。オープン版ファームウェア、アプリ、 JSON フォーマットはすべてオープンソースです。

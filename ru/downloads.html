Прошивка

Проще всего нажать кнопку Установить прошивку на главной странице (Chrome или Edge на компьютере, плата по USB). Те же файлы есть на GitHub: релизы Radar Base. Прошивка 0.9.2 и новее включает приложения радара (3D-присутствие; дыхание и пульс).

Radar Studio для Windows

Скачать Radar Studio 0.9.1 для Windows (64 бита, около 60 МБ, установка не нужна; SHA-256 указан в релизе).

«Windows защитила ваш компьютер»

Radar Studio пока не подписан цифровой подписью, поэтому Windows SmartScreen может остановить его при первом запуске. Выберите Подробнее, затем Выполнить в любом случае. Сверьте SHA-256 файла со страницей релиза, если хотите убедиться, что это оригинал.

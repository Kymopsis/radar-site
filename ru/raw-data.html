Сырые данные и ваши алгоритмы

Radar Base может передавать по USB сырые данные радара (каждый чирп, оба приёмных канала). Открытая прошивка включает этот поток и его настройки; Radar Studio для Windows показывает и обрабатывает их и открывает эти виды с комплектом разработчика (Загрузки).

Где запускать алгоритм

Сначала сделайте прототип на ПК. Затем проверьте, справится ли с задачей собственное аппаратное обеспечение радара для FFT и CFAR; если да, алгоритм должен работать на радаре, а наружу выходят только результаты. Иначе проверьте ESP32, и оставляйте алгоритм только на ПК, если не подходит ни то, ни другое.

Проверьте канал данных

Приложение → Сырые данные и настройки радара → Запустить тест. Он на несколько секунд запускает приложение сырых данных и проверяет каждый блок: повреждённых и пропущенных блоков должно быть 0.

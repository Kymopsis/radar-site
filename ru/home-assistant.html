Home Assistant

Появится в ближайшее время. Эта страница описывает, как будет работать интеграция; сейчас она в разработке.

Radar Base появится в Home Assistant сам через обнаружение MQTT. Вы используете собственный брокер MQTT; обычный выбор — дополнение Mosquitto broker в Home Assistant. Kymopsis не запускает ни брокера, ни облака.

Планируемая настройка

  1. В Home Assistant установите дополнение Mosquitto broker и интеграцию MQTT.
  2. В приложении Radar Base: Настройки устройства → Умный дом → введите адрес брокера, пользователя и пароль.
  3. Radar Base появится в разделе Настройки → Устройства.

Дыхание и пульс предназначены только для оздоровительных целей и не для медицинского применения.

Radar Base

Radar Base подключает радарный модуль 60 GHz (mmWave) к вашему компьютеру, телефону и умному дому. Радарную работу выполняет собственный чип радара; Radar Base загружает в него радарные приложения, превращает их результаты в один простой формат JSON и отдаёт их по USB и Wi-Fi.

Запустите готовое радарное приложениеПоложение людей в 3D, обнаружение падений, дыхание и пульс. Без программирования. Работайте в браузере по USBПодключите, откройте этот сайт в Chrome или Edge — и всё. Wi-Fi не нужен. Подключите к домашнему Wi-FiОткрывайте по адресу http://kymradar.local с любого телефона или компьютера дома. Создайте собственную интеграциюЧитайте результаты в формате JSON по USB или WebSocket из любой программы.

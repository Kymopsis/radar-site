Работа по USB в браузере

Приложение Radar Base работает в Chrome или Edge на вашем компьютере и общается с платой по USB-кабелю (Web Serial). Ничего устанавливать не нужно, Wi-Fi не используется.

Шаги

  1. Подключите порт USB контроллера к компьютеру.
  2. Откройте radar.kymopsis.com/app в Chrome или Edge.
  3. Нажмите Подключить USB в верхней панели и выберите «USB JTAG/serial debug unit».
  4. Статус станет зелёным. Выберите задачу на главной странице.

Браузер один раз для каждого сайта спрашивает разрешение на использование порта; больше ничего на вашем компьютере не передаётся.

Что работает по USB

ФункцияПо USB
Запустить сценарий, живые виды, настройки сценарияДа
Настройки сырых данных и самотест канала данныхДа
Запись прошивки в радар (dev kit)Да
Настройка домашнего Wi-FiДа (имя сети и пароль без пробелов)
Загрузка и удаление файлов прошивкиНет - для этого используйте Wi-Fi

Только одна программа за раз

USB-порт может быть открыт только в одной программе. Закройте любой последовательный терминал перед подключением браузера, и наоборот.

Браузеры

Web Serial доступен в Chrome, Edge и других браузерах на основе Chromium на компьютерах. Safari и Firefox его не поддерживают; в них, а также на телефонах используйте Домашний Wi-Fi.

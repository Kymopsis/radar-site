Dados brutos e seus próprios algoritmos

O Radar Base pode transmitir por USB os dados brutos do radar (cada chirp, os dois canais de recepção). O firmware aberto inclui esse fluxo e seus ajustes; a ferramenta de PC para visualizar e processar os dados brutos não faz parte do repositório público.

O que o firmware aberto oferece

RecursoOnde
Ajustes de dados brutos: chirp, ganho, filtros, antenasApp → Dados brutos e ajustes do radar, ou console cfg <key> <value>
Autoteste do link de dados: cada bloco é verificadoApp → Dados brutos e ajustes do radar → Executar teste
Resultados em JSON para o seu próprio códigoResultados JSON e API

Onde executar um algoritmo

Faça o protótipo no PC. Depois verifique se o hardware de FFT e CFAR do próprio radar dá conta; se sim, ele deve rodar no radar e só os resultados saem dele. Caso contrário, verifique o ESP32, e deixe no PC apenas se nenhum dos dois servir.

Verifique o link de dados

App → Dados brutos e ajustes do radar → Executar teste. Ele executa o app de dados brutos por alguns segundos e verifica cada bloco: os blocos corrompidos e os ausentes devem ser 0.

Resultados JSON e API

Todo cliente - o app, o Home Assistant, o seu próprio código - lê os mesmos resultados: um objeto JSON por linha, versão de esquema 0.

Onde lê-los

ConexãoComo
USBEnvie jsonout on no console serial; as linhas JSON chegam entre as linhas de log
Wi-FiWebSocket ws://kymradar.local/ws (uma ou mais linhas por mensagem)

Mensagens

tCamposObservações
capapp (hd3d, fall, vital), mounts, mountEnviada quando um cenário inicia, quando a montagem muda e a cada 5 s
targetsts (ms), targets: [{id, x, y, z}]Metros. x para a direita, y afastando-se do radar (plano do chão quando está no teto), z para cima
zoneszones: [{id, occupied}]Áreas 1-4; enviada a cada mudança e a cada segundo
fallstate (none, normal, fall), countEnviada a cada mudança e a cada segundo
vitalts, br, hr (por minuto), dist (m)As frequências são omitidas enquanto ninguém é medido

Toda mensagem tem "v": 0. Ignore mensagens com outra versão.

{"v":0,"t":"cap","app":"hd3d","mounts":["ceiling","side"],"mount":"side","fov_deg":55}
{"v":0,"t":"targets","ts":42097,"targets":[{"id":1,"x":0.268,"y":1.42,"z":0.05}]}

Comandos (console USB ou app)

ComandoO que faz
verPergunta a versão ao app do radar
ram <file>Executa um app do radar a partir da memória do radar
resetReinicia o radar a partir da flash
jsonout on/offResultados JSON por USB
tf 0201 13000000 / 14000000Presença 3D: montagem no teto / na parede
cfg [key value]Configurações de dados brutos
wifi [ssid password], wifi forget, wifi scanWi-Fi de casa
api files/cfg/wifi/scan/mqtt/batchInformações do dispositivo em uma linha JSON (usado pelo app por USB)
mqtt <host> [port] [user] [pass], mqtt offHome Assistant pelo seu próprio broker MQTT
board [profile]Mostrar ou definir o perfil de placa
u0raw on/offEncaminhar a porta do app do radar byte a byte (captura bruta)
batch start <firmware>, batch stopGravação em lote (firmware do kit de desenvolvimento)

API HTTP (Wi-Fi)

GET /api/files, GET/POST /api/cfg, GET/POST /api/wifi, GET /api/wifi/scan, POST /api/run?op=..., POST /api/tf?type=&data=, GET /api/log?since=. As credenciais só são enviadas no corpo de um POST.

Cliente de exemplo em Python: python app_views.py --serial COM5 na pasta pc-gui.

Volume, módulos pré-gravados ou firmware personalizado: Kymopsis B2B

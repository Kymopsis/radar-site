開發套件雷達寫入模組

Radar Base 韌體有兩個版本，由同一份原始碼建置：

版本能做什麼
開放版本站介紹的一切：從雷達記憶體執行所有雷達應用、JSON、網頁應用程式、Wi-Fi、智慧家庭
開發套件版開放版 + 一個額外模組，可寫入雷達自己的快閃記憶體

模組的功能

把應用寫入雷達的快閃記憶體後，雷達上電就會自行啟動，不需要 Radar Base 先載入。模組在每次寫入前都會備份雷達目前的快閃記憶體； 備份失敗就不會寫入任何內容。備份可隨時從應用程式還原。

開發套件韌體如何交付

開發套件韌體已預先安裝在開發套件板上。更新會透過電子郵件通知買家；開發套件韌體不提供公開下載。開放版韌體將以原始碼形式發佈到公開儲存庫，發佈後會在本頁提供連結。

批次寫入

要連續處理多個模組：先選一次韌體，再逐一接上模組。每個模組都會被偵測、視需要備份、寫入、驗證、從快閃記憶體啟動，並讀取其版本。頁面與板上的指示燈顯示 PASS 或 FAIL，計數器會累加，每個模組在可下載的 CSV 紀錄中佔一行。

它不做什麼

  • 不連上網際網路。
  • 不蒐集、儲存或傳送任何資料。
  • 韌體的其他部分都不依賴它。

它是閉源的，因為寫入時載入雷達的那個小型輔助程式不屬於我們，無法公開。在開發套件裝置上， 該輔助程式以每台裝置專屬的金鑰加密存放。

沒有它

開放版韌體同樣可以從雷達記憶體執行每個雷達應用（執行情境）。你只是少了「不需要 Radar Base 就能自行啟動」 這項便利。開放版韌體、應用程式和 JSON 格式本身就是開放的設計，應用程式和 JSON 格式都在本站有說明。

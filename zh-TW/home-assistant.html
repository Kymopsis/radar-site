Home Assistant

Radar Base 會透過 MQTT 自動探索出現在 Home Assistant 中。你使用自己的 MQTT 代理伺服器（broker），通常是 Home Assistant 裡的 Mosquitto broker 附加元件。Kymopsis 不運行任何代理伺服器，也沒有雲端；資料不會離開你的網路。

你需要準備

  • 具備 Mosquitto broker 附加元件和 MQTT 整合的 Home Assistant，或你自己運行的其他 MQTT 代理伺服器。

記下代理伺服器的位址、連接埠（通常是 1883）、使用者名稱和密碼。

  • 一個 2.4 GHz Wi-Fi 網路，或 2.4 GHz 與 5 GHz 使用同一個名稱的雙頻網路。ESP32-S3 沒有

5 GHz 無線電。

  • Radar Base 韌體 0.9.1 或更新版本（在瀏覽器中安裝）。

設定步驟

  1. 連上 Wi-Fi：開啟 Radar Base 應用程式（透過 USB，或板子的熱點），裝置設定，Wi-Fi。
  2. 在裝置設定的「智慧家庭」中：填入代理伺服器位址、連接埠、使用者名稱和密碼，然後開啟 MQTT。
  3. 在 Home Assistant 中開啟「設定 → 裝置與服務 → MQTT」。Kymopsis Radar Base 已在其中，實體齊全。 無需其他設定。

上線與離線

板子會發布一個可用性主題。在板子上關閉 MQTT 後，裝置會立即變為不可用。 如果板子斷電或斷開 Wi-Fi，代理伺服器會在約 45 秒後將其標記為不可用；板子重新連線後會自動恢復。

疑難排解

問題處理方法
裝置沒有出現查看板子的「智慧家庭」頁面：必須顯示已連線。檢查代理伺服器中的使用者名稱和密碼。
板子無法連上 Wi-Fi使用 2.4 GHz 網路，或使用同一名稱的雙頻網路；僅 5 GHz 的網路無法使用。
kymradar.local 打不開該電腦上的 VPN 或代理可能會接管 .local 名稱；請關閉它，或讓 .local 直連，也可以直接開啟板子的 IP 位址。
距離顯示為英尺Home Assistant 使用你設定的單位系統：設定 → 系統 → 一般 → 單位系統：公制。

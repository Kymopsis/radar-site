Home Assistant

即將推出。本頁說明整合的運作方式，目前正在開發中。

Radar Base 將透過 MQTT 自動探索出現在 Home Assistant 中。你使用自己的 MQTT 代理伺服器；常見的選擇是 Home Assistant 裡的 Mosquitto broker 附加元件。Kymopsis 不運行任何代理伺服器，也沒有雲端。

規劃中的實體

實體類型來源
有人狀態二元感測器3D 人員存在
人數感測器3D 人員存在
區域 1-4 有人二元感測器3D 人員存在
偵測到跌倒二元感測器和事件跌倒偵測
呼吸率、心率感測器（診斷）呼吸與心率
安裝方式（天花板 / 牆面）選擇3D 人員存在

規劃中的設定步驟

  1. 在 Home Assistant 中安裝 Mosquitto broker 附加元件和 MQTT 整合。
  2. 在 Radar Base 應用程式中：裝置設定 → 智慧家庭 → 填入代理伺服器位址、使用者名稱和密碼。
  3. Radar Base 會出現在「設定 → 裝置」中。

呼吸和心率僅供健康保健用途，非醫療用途。

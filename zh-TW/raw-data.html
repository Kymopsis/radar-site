原始資料與你自己的演算法

Radar Base 可以透過 USB 傳輸雷達的原始資料（每個 chirp、兩個接收通道）。開放版韌體包含這個資料流及其設定；用於檢視和處理原始資料的電腦工具不在公開儲存庫中。

開放版韌體提供什麼

功能位置
原始資料設定：chirp、增益、濾波器、天線應用程式 → 原始資料與雷達設定，或主控台 cfg <key> <value>
資料鏈路自我測試：檢查每個區塊應用程式 → 原始資料與雷達設定 → 開始測試
供你自己的程式碼使用的 JSON 結果JSON 結果與 API

演算法該在哪裡執行

先在電腦上做原型。接著看雷達自己的 FFT 和 CFAR 硬體能否勝任；如果可以，就應該在雷達上執行，只把結果傳出來。 否則再看 ESP32 能否勝任；兩者都不行時才留在電腦上。

檢查資料鏈路

應用程式 → 原始資料與雷達設定 → 開始測試。它會執行原始資料應用幾秒鐘並檢查每個區塊： 損毀區塊和遺失區塊都應為 0。

大量採購、預燒錄模組或客製韌體： Kymopsis B2B

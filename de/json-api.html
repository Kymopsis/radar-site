JSON-Ergebnisse und API

Jeder Client - die App, Home Assistant, Ihr eigener Code - liest dieselben Ergebnisse: ein JSON-Objekt pro Zeile, Schemaversion 0.

Wo man sie liest

VerbindungWie
USBSenden Sie jsonout on an die serielle Konsole; JSON-Zeilen kommen zwischen den Log-Zeilen an
Wi-FiWebSocket ws://kymradar.local/ws (eine oder mehrere Zeilen pro Nachricht)

Nachrichten

tFelderHinweise
capapp (hd3d, fall, vital), mounts, mountWird gesendet, wenn ein Szenario startet, wenn sich die Montage ändert, und alle 5 s
targetsts (ms), targets: [{id, x, y, z}]Meter. x rechts, y vom Radar weg (Bodenebene bei Deckenmontage), z nach oben
zoneszones: [{id, occupied}]Bereiche 1-4; bei Änderung und jede Sekunde gesendet
fallstate (none, normal, fall), countBei Änderung und jede Sekunde gesendet
vitalts, br, hr (pro Minute), dist (m)Raten entfallen, solange niemand gemessen wird

Jede Nachricht enthält "v": 0. Ignorieren Sie Nachrichten mit einer anderen Version.

{"v":0,"t":"cap","app":"hd3d","mounts":["ceiling","side"],"mount":"side","fov_deg":55}
{"v":0,"t":"targets","ts":42097,"targets":[{"id":1,"x":0.268,"y":1.42,"z":0.05}]}

Befehle (USB-Konsole oder App)

BefehlWas er tut
verFragt die Radar-App nach ihrer Version
ram <file>Startet eine Radar-App aus dem Speicher des Radars
resetStartet das Radar aus seinem Flash neu
jsonout on/offJSON-Ergebnisse über USB
tf 0201 13000000 / 140000003D-Anwesenheit: Decken- / Wandmontage
cfg [key value]Rohdaten-Einstellungen
wifi [ssid password], wifi forget, wifi scanHeim-Wi-Fi
api files/cfg/wifi/scan/mqtt/batchGeräteinfos als eine JSON-Zeile (von der App über USB genutzt)

board [profile]Board-Profil anzeigen oder setzen
u0raw on/offDen Port der Radar-App Byte für Byte weiterleiten (Rohmitschnitt)
batch start <firmware>, batch stopStapel-Flashen (Dev-Kit-Firmware)

HTTP-API (Wi-Fi)

GET /api/files, GET/POST /api/cfg, GET/POST /api/wifi, GET /api/wifi/scan, POST /api/run?op=..., POST /api/tf?type=&data=, GET /api/log?since=. Zugangsdaten werden nur im POST-Body gesendet.

Beispiel-Client in Python: python app_views.py --serial COM5 im Ordner pc-gui.

Stückzahlen, vorgeflashte Module oder eigene Firmware: Kymopsis B2B

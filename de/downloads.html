Firmware

Am einfachsten geht es mit der Schaltfläche Firmware installieren auf der Startseite (Chrome oder Edge am Desktop, Board per USB). Dieselben Dateien liegen auch auf GitHub: Radar Base Releases. Firmware 0.9.2 und neuer enthält die Radar-Apps (3D-Anwesenheit; Atem- und Herzfrequenz).

Radar Studio für Windows

Radar Studio 0.9.1 für Windows herunterladen (64 Bit, etwa 60 MB, keine Installation nötig; SHA-256 im Release).

„Der Computer wurde durch Windows geschützt“

Radar Studio ist noch nicht code-signiert, deshalb kann Windows SmartScreen es beim ersten Mal stoppen. Wählen Sie Weitere Informationen und dann Trotzdem ausführen. Prüfen Sie den SHA-256 der Datei anhand der Release-Seite, wenn Sie sichergehen wollen, dass es das Original ist.

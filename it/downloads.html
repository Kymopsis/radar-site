Firmware

Il modo più semplice è il pulsante Installa il firmware nella pagina iniziale (Chrome o Edge su desktop, scheda via USB). Gli stessi file sono su GitHub: release di Radar Base. Il firmware 0.9.2 e successivi includono le app radar (presenza 3D; frequenza respiratoria e cardiaca).

Radar Studio per Windows

Scarica Radar Studio 0.9.1 per Windows (64 bit, circa 60 MB, senza installazione; SHA-256 nella release).

Funziona conFunzioni
Qualsiasi Radar BaseConnessione via USB, viste per scenario, impostazioni comuni, configurazione smart home (MQTT)
Kit di sviluppo Kymopsis Radar BaseInoltre dati grezzi, range-Doppler, impostazioni di forma d'onda e filtri, i tuoi algoritmi, parametri vitali / HRV

«Windows ha protetto il PC»

Radar Studio non è ancora firmato digitalmente, quindi Windows SmartScreen può bloccarlo la prima volta. Scegli Ulteriori informazioni, poi Esegui comunque. Confronta lo SHA-256 del file con la pagina della release se vuoi essere sicuro che sia l'originale.

Risultati JSON e API

Ogni client - l'app, Home Assistant, il tuo codice - legge gli stessi risultati: un oggetto JSON per riga, versione dello schema 0.

Dove leggerli

ConnessioneCome
USBInvia jsonout on sulla console seriale; le righe JSON arrivano tra le righe di log
Wi-FiWebSocket ws://kymradar.local/ws (una o più righe per messaggio)

Messaggi

tCampiNote
capapp (hd3d, fall, vital), mounts, mountInviato all'avvio di uno scenario, quando cambia il montaggio e ogni 5 s
targetsts (ms), targets: [{id, x, y, z}]Metri. x a destra, y in allontanamento dal radar (piano del pavimento se è a soffitto), z verso l'alto
zoneszones: [{id, occupied}]Aree 1-4; inviato a ogni cambiamento e ogni secondo
fallstate (none, normal, fall), countInviato a ogni cambiamento e ogni secondo
vitalts, br, hr (al minuto), dist (m)Le frequenze sono omesse finché nessuno viene misurato

Ogni messaggio ha "v": 0. Ignora i messaggi con un'altra versione.

{"v":0,"t":"cap","app":"hd3d","mounts":["ceiling","side"],"mount":"side","fov_deg":55}
{"v":0,"t":"targets","ts":42097,"targets":[{"id":1,"x":0.268,"y":1.42,"z":0.05}]}

Comandi (console USB o app)

ComandoCosa fa
verChiede la versione all'app radar
ram <file>Esegue un'app radar dalla memoria del radar
resetRiavvia il radar dalla sua flash
jsonout on/offRisultati JSON via USB
tf 0201 13000000 / 14000000Presenza 3D: montaggio a soffitto / a parete
cfg [key value]Impostazioni dei dati grezzi
wifi [ssid password], wifi forget, wifi scanWi-Fi di casa
api files/cfg/wifi/scan/mqtt/batchInfo del dispositivo in una riga JSON (usato dall'app via USB)
mqtt <host> [port] [user] [pass], mqtt offHome Assistant tramite il tuo broker MQTT
board [profile]Mostra o imposta il profilo scheda
u0raw on/offInoltra la porta dell'app radar byte per byte (acquisizione grezza)
batch start <firmware>, batch stopScrittura in serie (firmware del kit di sviluppo)

API HTTP (Wi-Fi)

GET /api/files, GET/POST /api/cfg, GET/POST /api/wifi, GET /api/wifi/scan, POST /api/run?op=..., POST /api/tf?type=&data=, GET /api/log?since=. Le credenziali vengono inviate solo nel corpo di una POST.

Client di esempio in Python: python app_views.py --serial COM5 nella cartella pc-gui.

Volumi, moduli già programmati o firmware personalizzato: Kymopsis B2B

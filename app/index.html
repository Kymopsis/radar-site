Write firmware to the radar

Puts an app into the radar's own flash so it starts by itself at power-up. The current firmware is saved first and can be put back at any time.

Included with the Kymopsis development kit firmware.

This is the open firmware. It runs every radar app from the radar's memory (see Run a scenario) but does not write the radar's flash. Writing needs the dev-kit firmware.

About the development kit

1. Choose the app

Apps are files stored on Radar Base. Add new ones under Device settings → Firmware files.

2. Write

The radar's current firmware is backed up first (saved as bakN.bin). If the backup fails, nothing is written. Takes about 15 seconds.

About this function

Writing the radar's flash is done by a small closed module that is part of the dev-kit firmware only. That is its only job: it does not connect to the internet and collects no data. Everything else is open source, and every radar app can also run from memory without it.

Batch flashing

Choose a firmware once. Each module is flashed as soon as it is connected; swap modules when the light turns blue.

Raw data and your own algorithms

Radar Base can stream the radar's raw data (every chirp, both receive channels) over USB. The open firmware includes this stream and its settings; the PC tool for viewing and processing raw data is not published yet.

What the open firmware gives you

FeatureWhere
Raw-data settings: chirp, gain, filters, antennasApp → Raw data & radar settings, or console cfg <key> <value>
Data-link self-test: every block checkedApp → Raw data & radar settings → Run test
Results as JSON for your own codeJSON and API

Where to run an algorithm

Prototype on a PC. Then check whether the radar's own FFT and CFAR hardware can do the job; if so it should run on the radar and only results leave it. Otherwise check the ESP32, and keep it on the PC only if neither fits.

Check the data link

App → Raw data & radar settings → Run test. It runs the raw-data app for a few seconds and checks every block: corrupted and missing blocks should both be 0.

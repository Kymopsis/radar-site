Firmware

The easiest way is the Install firmware button on the home page (Chrome or Edge on a desktop, board on USB). The same files are on GitHub: Radar Base releases. Firmware 0.9.2 and later include the radar apps (3D presence; breathing and heart rate).

Radar Studio for Windows

Download Radar Studio 0.9.1 for Windows (64-bit, about 60 MB, no installation needed; SHA-256 in the release).

Works withFeatures
Any Radar BaseConnect over USB, scenario views, common settings, smart home (MQTT) setup
Kymopsis Radar Base dev kitAlso raw data, range-Doppler, waveform and filter settings, your own algorithms, vital signs / HRV

"Windows protected your PC"

Radar Studio is not code-signed yet, so Windows SmartScreen may stop it the first time. Choose More info, then Run anyway. Check the file's SHA-256 against the release page if you want to be sure it is the original.

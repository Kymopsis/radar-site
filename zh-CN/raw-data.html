原始数据与你自己的算法

Radar Base 可以通过 USB 传输雷达的原始数据（每个 chirp、两个接收通道）。开放版固件包含这个数据流及其设置；用于查看和处理原始数据的电脑工具不在公开仓库中。

开放版固件提供什么

功能位置
原始数据设置：chirp、增益、滤波器、天线应用 → 原始数据与雷达设置，或控制台 cfg <key> <value>
数据链路自检：检查每个数据块应用 → 原始数据与雷达设置 → 开始测试
供你自己的代码使用的 JSON 结果JSON 结果与 API

算法该在哪里运行

先在电脑上做原型。然后看雷达自己的 FFT 和 CFAR 硬件能否胜任；如果可以，就应该在雷达上运行，只把结果传出来。 否则再看 ESP32 能否胜任；两者都不行时才留在电脑上。

检查数据链路

应用 → 原始数据与雷达设置 → 开始测试。它会运行原始数据应用几秒钟并检查每个数据块： 损坏块和缺失块都应为 0。

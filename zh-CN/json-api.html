JSON 结果与 API

所有客户端 - 应用、Home Assistant、你自己的代码 - 读取的都是同一种结果：每行一个 JSON 对象， 模式版本 0。

在哪里读取

连接方式方法
USB在串口控制台发送 jsonout on；JSON 行会夹在日志行之间输出
Wi-FiWebSocket ws://kymradar.local/ws（每条消息一行或多行）

消息

t字段说明
capapp (hd3d, fall, vital), mounts, mount场景启动时、安装方式变化时，以及每 5 秒发送
targetsts (ms), targets: [{id, x, y, z}]单位为米。x 向右，y 远离雷达（吸顶时为地面平面），z 向上
zoneszones: [{id, occupied}]区域 1-4；变化时和每秒发送
fallstate (none, normal, fall), count变化时和每秒发送
vitalts, br, hr（每分钟）, dist (m)没有测量对象时省略速率

每条消息都带有 "v": 0。请忽略其他版本的消息。

{"v":0,"t":"cap","app":"hd3d","mounts":["ceiling","side"],"mount":"side","fov_deg":55}
{"v":0,"t":"targets","ts":42097,"targets":[{"id":1,"x":0.268,"y":1.42,"z":0.05}]}

命令（USB 控制台或应用）

命令作用
ver向雷达应用查询版本
ram <file>从雷达内存运行雷达应用
reset从闪存重启雷达
jsonout on/off通过 USB 输出 JSON 结果
tf 0201 13000000 / 140000003D 存在：吸顶 / 墙面安装
cfg [key value]原始数据设置
wifi [ssid password], wifi forget, wifi scan家庭 Wi-Fi
api files/cfg/wifi/scan/mqtt/batch以一行 JSON 返回设备信息（应用通过 USB 使用）
mqtt <host> [port] [user] [pass], mqtt off通过你自己的 MQTT 代理（broker）连接 Home Assistant
board [profile]显示或设置板型配置
u0raw on/off原样转发雷达应用端口的字节（原始抓取）
batch start <firmware>, batch stop批量写入（开发套件固件）

HTTP API（Wi-Fi）

GET /api/files, GET/POST /api/cfg, GET/POST /api/wifi, GET /api/wifi/scan, POST /api/run?op=..., POST /api/tf?type=&data=, GET /api/log?since=。凭据只会放在 POST 请求体中发送。

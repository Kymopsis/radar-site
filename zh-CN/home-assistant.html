Home Assistant

Radar Base 会通过 MQTT 自动发现出现在 Home Assistant 中。你使用自己的 MQTT 代理（broker），通常是 Home Assistant 里的 Mosquitto broker 加载项。Kymopsis 不运行任何代理，也没有云端；数据不会离开你的网络。

你需要准备

  • 带有 Mosquitto broker 加载项和 MQTT 集成的 Home Assistant，或你自己运行的其他 MQTT 代理。

记下代理的地址、端口（通常是 1883）、用户名和密码。

  • 一个 2.4 GHz Wi-Fi 网络，或 2.4 GHz 与 5 GHz 使用同一个名称的双频网络。ESP32-S3 没有

5 GHz 射频。

  • Radar Base 固件 0.9.1 或更高版本（在浏览器中安装）。

设置步骤

  1. 连接 Wi-Fi：打开 Radar Base 应用（通过 USB，或板子的热点），设备设置，Wi-Fi。
  2. 在设备设置的“智能家居”中：填入代理地址、端口、用户名和密码，然后打开 MQTT。
  3. 在 Home Assistant 中打开“设置 → 设备与服务 → MQTT”。Kymopsis Radar Base 已在其中，实体齐全。 无需其他配置。

在线与离线

板子会发布一个可用性主题。在板子上关闭 MQTT 后，设备会立即变为不可用。 如果板子断电或断开 Wi-Fi，代理会在约 45 秒后将其标记为不可用；板子重新连接后会自动恢复。

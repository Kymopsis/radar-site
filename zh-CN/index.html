Radar Base

Radar Base 把 60 GHz 毫米波雷达模块连接到你的电脑、手机和智能家居。 雷达工作由雷达自己的芯片完成；Radar Base 把雷达应用加载进去，把结果转成一种简单的 JSON 格式，并通过 USB 和 Wi-Fi 提供出来。

运行现成的雷达应用3D 人员位置、跌倒检测、呼吸和心率。无需编程。 通过 USB 在浏览器中使用插上线，在 Chrome 或 Edge 中打开本站即可。无需 Wi-Fi。 接入家庭 Wi-Fi在家里用任何手机或电脑访问 http://kymradar.local。 开发自己的集成在任何程序中通过 USB 或 WebSocket 以 JSON 读取结果。

整体结构

部分作用
雷达模块运行雷达应用：每个应用在雷达上完成整条信号处理链并上报结果
Radar Base (ESP32-S3)加载雷达应用，把结果转成 JSON，推送原始数据流，提供网页应用，接入你的 Wi-Fi
网页应用选择任务、查看实时结果、修改设置。Wi-Fi 和 USB 下是同一个应用，支持 11 种语言
你自己的代码通过 USB 或 WebSocket 读取 JSON 结果
智能家居通过 MQTT 接入 Home Assistant（自动发现），ESPHome 组件
